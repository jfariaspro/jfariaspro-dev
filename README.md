Un portafolio web moderno, interactivo y altamente optimizado construido para reflejar mi experiencia como **Ingeniero Backend & Cloud / Desarrollador FullStack**. Diseñado con un enfoque en estética *Premium*, animaciones fluidas y arquitectura de alto rendimiento.

## ✨ Características Principales

*   **Diseño Premium y Glassmorphism:** Interfaz limpia con efectos de cristal (backdrop-blur), bordes sutiles y degradados dinámicos que se adaptan al tema.
*   **Modo Oscuro / Claro Perfecto:** Integración nativa con `next-themes` para transiciones fluidas entre paletas de colores sin destellos (FOUC) en el servidor.
*   **Animaciones Avanzadas (Framer Motion & CSS):** 
    *   Logo de circuito SVG animado infinitamente.
    *   Efecto de máquina de escribir (`Typewriter`) optimizado.
    *   Cinta infinita (Marquee) impulsada por GPU para los colaboradores.
    *   Figuras geométricas flotantes en el fondo.
*   **Rendimiento Extremo:** Utilizando App Router de Next.js 15, Server Components y optimización agresiva de imágenes locales con `next/image`.
*   **Secciones Integradas:** Experiencia, Proyectos (con modales interactivos), Tecnologías, Certificaciones y una cinta de Marcas/Colaboradores.
*   **Contacto Directo:** Enrutamiento directo a WhatsApp preconfigurado para contacto inmediato.

## 🚀 Tecnologías

*   **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
*   **Librería UI:** [React 19](https://react.dev/)
*   **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
*   **Animaciones:** [Framer Motion](https://www.framer.com/motion/) & CSS puro (Keyframes)
*   **Temas:** [next-themes](https://github.com/pacocoursey/next-themes)
*   **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)

## 💻 Instalación y Desarrollo Local

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/modern-portfolio.git
   ```
2. Navega al directorio:
   ```bash
   cd modern-portfolio
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 🏗️ Arquitectura del Código

*   `/src/app`: Rutas de Next.js, Layout principal y configuración global de CSS.
*   `/src/components`: Componentes modulares y reutilizables (Hero, Navbar, Projects, Collaborators, AnimatedLogo, etc.).
*   `/public`: Archivos estáticos optimizados (Logos, PDFs, Imágenes de fondo).
